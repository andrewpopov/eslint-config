# Support

Use [GitHub Issues](https://github.com/andrewpopov/eslint-config/issues) for
reproducible bugs and scoped feature proposals. Include the package version,
Node and ESLint versions, expected behavior, actual behavior, and a minimal
reproduction (an `eslint.config.*` snippet plus the offending file is usually
enough).

Support is best-effort; no response-time or compatibility SLA is offered.
Questions about a consuming application's own lint setup outside this kit's
presets belong with that application. Security reports must follow
[SECURITY.md](./SECURITY.md), not public issues.
